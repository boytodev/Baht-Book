# สมุดเงิน

ระบบบันทึกรายรับ–รายจ่ายส่วนตัว สร้างด้วย **Next.js (App Router) + TypeScript + Supabase**
หน้าเว็บเดียวใช้ได้ทั้งเดสก์ท็อปและมือถือ รองรับโหมดมืด และแสดงปี พ.ศ.

## ฟีเจอร์

- สมัครสมาชิก / เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน (Supabase Auth)
- เพิ่ม / ลบรายการรายรับ–รายจ่าย เลือกหมวดหมู่ วันที่ และบันทึกเพิ่มเติม
- ภาพรวมรายเดือน: ยอดคงเหลือ รายรับ รายจ่าย อัตราการออม รายจ่ายแยกหมวด
- หน้ารายการ: กรองรายรับ/รายจ่าย จัดกลุ่มตามวัน พร้อมยอดสุทธิรายวัน
- หน้าสถิติ: กราฟรายจ่ายรายวัน เทียบรายรับ–รายจ่าย รายจ่ายสูงสุด
- เลือกดูย้อนหลังรายเดือนได้ (`?m=2026-10`)
- ส่งออกข้อมูลทั้งหมดเป็น CSV (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน)
- โหมดมืด (สลับที่หน้าบัญชี)
- ข้อมูลแยกตามผู้ใช้ด้วย Row Level Security ของ PostgreSQL

## เริ่มใช้งาน

### 1. สร้างโปรเจกต์ Supabase (ฟรี)

1. สมัครและสร้างโปรเจกต์ที่ <https://supabase.com>
2. เปิด **SQL Editor** แล้ววางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งไฟล์ จากนั้นกด **Run**
   ไฟล์นี้สร้างตาราง นโยบายความปลอดภัย และหมวดหมู่เริ่มต้นให้ผู้ใช้ใหม่อัตโนมัติ
3. ไปที่ **Project Settings → API** คัดลอก **Project URL** และ **anon / publishable key**

### 2. ตั้งค่าและรัน

```bash
npm install
cp .env.example .env.local     # แล้วใส่ URL และ key ที่คัดลอกมา
npm run dev                    # เปิด http://localhost:3000
```

เปิดหน้าเว็บ กด "สมัครสมาชิกด้วยอีเมลนี้" แล้วเริ่มจดรายการได้เลย

> **เรื่องการยืนยันอีเมล:** โดยปกติ Supabase จะส่งอีเมลให้กดยืนยันก่อนเข้าระบบได้
> ถ้าต้องการทดลองใช้เร็วๆ ให้ปิดที่ **Authentication → Sign In / Providers → Email → Confirm email**
> (ควรเปิดกลับเมื่อใช้งานจริง) และต้องตั้ง **Authentication → URL Configuration → Site URL**
> ให้ตรงกับโดเมนที่ deploy เพื่อให้ลิงก์ในอีเมลกลับมาที่เว็บของคุณ

### 3. Deploy (ฟรี)

1. push โค้ดขึ้น GitHub
2. นำเข้าโปรเจกต์ที่ <https://vercel.com> (หรือ Cloudflare Pages)
3. ใส่ Environment Variables สองตัวเดียวกับ `.env.local`
4. อัปเดต Site URL ใน Supabase เป็นโดเมนที่ได้

## โครงสร้างโค้ด

```
supabase/schema.sql          ตาราง + RLS + ทริกเกอร์หมวดเริ่มต้น
src/proxy.ts                 รีเฟรช session และป้องกันหน้าที่ต้องล็อกอิน
src/lib/supabase/            Supabase client ฝั่งเซิร์ฟเวอร์
src/lib/format.ts            แปลงสตางค์/บาท วันที่ไทย (พ.ศ.) เดือน
src/lib/data.ts              ดึงรายการและคำนวณสรุปยอด
src/lib/config.ts            ชื่อระบบ (แก้ที่นี่ที่เดียว)
src/app/(app)/               หน้า ภาพรวม / เพิ่มรายการ / รายการ / สถิติ / บัญชี
src/app/(app)/actions.ts     Server Actions: เพิ่ม ลบ ออกจากระบบ
src/app/login/               หน้าเข้าสู่ระบบ / สมัครสมาชิก
src/app/api/export/          ส่งออก CSV
src/app/globals.css          ธีมสว่าง/มืดและสไตล์ทั้งหมด
```

## หลักการที่ใช้

- **เก็บเงินเป็นสตางค์ (จำนวนเต็ม)** เช่น 85 บาท = 8500 เพื่อเลี่ยงทศนิยมคลาดเคลื่อน
  แปลงเป็นบาทเฉพาะตอนแสดงผล (`src/lib/format.ts`)
- **ไม่เก็บยอดสรุปในฐานข้อมูล** คำนวณจากรายการทุกครั้ง จึงไม่มีทางเพี้ยน
- **วันที่ใช้เขตเวลาไทย (Asia/Bangkok)** วันนี้จึงไม่คลาดเคลื่อนช่วงใกล้เที่ยงคืน
- **ความปลอดภัยอยู่ที่ฐานข้อมูล** ผู้ใช้เห็นและแก้ได้เฉพาะแถวของตัวเองผ่าน RLS
  และ Server Action ตรวจข้อมูลที่รับเข้ามาทุกครั้ง

## เปลี่ยนชื่อระบบ

แก้ `APP_NAME` และ `APP_TAGLINE` ใน `src/lib/config.ts`

## สิ่งที่ยังไม่ได้ทำ

- แก้ไขรายการที่บันทึกไปแล้ว (ตอนนี้ลบแล้วเพิ่มใหม่)
- จัดการหมวดหมู่เอง (เพิ่ม/ลบ/เปลี่ยนชื่อ) ตอนนี้ใช้หมวดเริ่มต้นที่สร้างให้ตอนสมัคร
- การแจ้งเตือนและสรุปรายสัปดาห์ (ดีไซน์ต้นแบบมี แต่ต้องมีงานเบื้องหลังเพิ่ม)
- ล้างข้อมูลทั้งหมดในคลิกเดียว
- เทสต์อัตโนมัติ
